# Log Analyzer

Консольная утилита для анализа лог-файлов веб-сервера (`access.log`). Фильтрует записи по периоду, считает статистику и сохраняет отчёт в JSON или Markdown.

Домашнее задание 3 по Java.

## Возможности

- Чтение одного или нескольких лог-файлов.
- Фильтрация по дате: `--from` и `--to`.
- Вывод отчёта в два формата: `json` или `markdown`.
- Проверка параметров: понятные ошибки для пропущенных или неверных аргументов.
- Защита от перезаписи: если выходной файл уже существует, утилита не запустится.
- Логирование через `java.util.logging`.

## Аргументы командной строки

| Аргумент | Краткая форма | Обязательный | Описание |
|----------|---------------|--------------|----------|
| `--path` | `-p` | да | Путь к лог-файлу. Можно указать несколько раз. |
| `--format` | `-f` | да | `json` или `markdown` |
| `--output` | `-o` | да | Путь к выходному файлу |
| `--from` | — | нет | Начальная дата, формат `YYYY-MM-DD` |
| `--to` | — | нет | Конечная дата, формат `YYYY-MM-DD` |

Правила проверки:
- дата `--from` должна быть раньше `--to`;
- расширение выходного файла должно соответствовать формату: `.json` для JSON, `.md` для Markdown;
- выходной файл не должен существовать.

## Примеры

Запустите `Logger.Main` в IntelliJ IDEA и передайте аргументы в конфигурации запуска (Run → Edit Configurations → Program arguments):

```text
# Отчёт в JSON за весь период
-p access.log -f json -o report.json

# Отчёт в Markdown за период
-p access.log -p other.log -f markdown -o report.md --from 2026-01-01 --to 2026-02-01
```

## Структура

```

├── Logger/
│   ├── Main.java            точка входа
│   ├── Configuration.java   разбор аргументов и проверки
│   ├── LogEntry.java        одна запись лога
│   ├── LogAnalyzer.java     чтение логов и подсчёт статистики
```

В папке `homework3/` лежат примеры: `access.log` (исходные данные) и `report.json` (результат).
